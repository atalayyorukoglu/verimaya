# Verimaya marka varlıkları (web)

Bu klasör **deploy edilen** web logolarını tutar. Native app ikonları ve Affinity kaynakları repo kökünde: `brand/`.

| Dosya | Ne için |
| --- | --- |
| `mark.svg` | Şeffaf mark (`currentColor`) — UI |
| `logo-horizontal.svg` | Yatay logo (ikon + VERIMAYA) |
| `logo-vertical.svg` | Dikey logo |
| `../../icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon.ico` | PWA / favicon / Apple touch |

UI bileşenleri: `BrandMark`, `SiteLogo` (`src/lib/components/`).
