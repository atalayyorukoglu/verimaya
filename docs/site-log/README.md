# Site Log taslakları

Bu klasör, [atalayyorukoglu.com](https://atalayyorukoglu.com) Log bölümü için **taslak** kayıtlardır.
Siteye henüz kopyalanmadı (`draft: true`).

## Biçim

- Başlık: 60–65 karakter
- Gövde: iki paragraf, toplam 350–400 karakter (boşluk dahil)
- Dil: `*-tr.md` + `*-en.md` çifti
- Ses: LOG-PROMPT kuralları (sakin operatör, sayı varsa sayı, jargon yok)

## Yayına alma

Dosyaları `sites/atalayyorukoglu/src/content/log/` altına taşıyıp `draft: false` yapın.
Ana sayfa Log bölümü karışık sırayla gösterir.
